# Loom And Lore Market

Project Title: WeaveHeritage – AI-Powered Handloom & Handicraft E-Commerce Marketplace



Develop a modern, fully responsive AI-powered e-commerce website for traditional Indian handloom and handicraft products.



Project Objective:

To create an online marketplace where local artisans can showcase and sell their handmade products, while customers can explore, purchase, and discover traditional Indian handicrafts.



1. User Roles



- Admin

- Artisan / Seller

- Customer / Buyer



2. Customer Features



- Customer registration and login.

- Browse all available handloom and handicraft products.

- Search products by name.

- Browse products by category.

- View product images, descriptions, prices, and artisan details.

- Add products to cart.

- Buy Now option.

- Place orders and view order history.

- View personalized product recommendations using AI.



3. Artisan Features



- Artisan registration and login.

- Add, edit, and delete products.

- Upload product images and descriptions.

- Manage product stock.

- View customer orders.

- Update order status.

- View sales reports.



4. Admin Features



- Manage customers and artisans.

- Manage product listings.

- Monitor orders.

- View overall sales and marketplace statistics.



5. AI-Powered Features



- AI Product Recommendation: Suggest products based on customer interests and browsing history.

- AI Chatbot: Answer customer questions about products, orders, categories, and the website.

- AI Product Description Generator: Automatically generate attractive product descriptions from product names and details.

- Smart Product Search: Help customers find products using natural language searches.



6. Product Categories



- Traditional Sarees

- Wooden Crafts

- Pottery

- Paintings

- Jewellery

- Lamps

- Bamboo Crafts



7. Technology Stack



- Frontend: HTML, CSS, JavaScript, Bootstrap

- Backend: Node.js and Express.js

- Database: MongoDB

- AI Integration: AI API for chatbot, recommendations, and description generation.



8. Design Requirements



- Modern and professional e-commerce interface.

- Traditional Indian handmade aesthetic.

- Beige, cream, and brown colour theme.

- Attractive product cards with realistic product images.

- Responsive design for desktop and mobile.

- Simple and user-friendly navigation.



Important: Build a fully functional website with working login, registration, product management, cart, checkout/order placement, and AI features. Use MongoDB for storing user, product, and order information. Do not create a static UI or dummy buttons.
